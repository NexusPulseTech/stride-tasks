## 2. Execution Engine

### 2.1. Nhập nhanh 1 dòng (`src/features/tasks/utils/smartTaskParser.ts`)

Ranh giới token: đầu chuỗi/khoảng trắng phía trước + khoảng trắng/cuối chuỗi phía sau (không dùng `\b` vì JS `\b` không hiểu ký tự có dấu). Không phân biệt hoa thường, chuẩn hóa Unicode NFC.

| Nhóm | Cú pháp | Kết quả |
| :--- | :--- | :--- |
| Thời lượng | `~15m`, `~1h`, `~1.5h`, `~90p`, `~45ph`, `~1giờ`, `~30phút`, `~2hrs` | `estimatedMinutes`. Nhiều token được **cộng dồn** (`~30m ~1h` = 90). Kẹp trong `1..1440` phút; token < 1 phút bị bỏ |
| Ghim | `!pin`, `!ghim`, `!!`, `!1`, `!p1` | `isPinned = true` |
| Trạng thái | `#todo` `#backlog` → `todo` · `#doing` `#danglam` `#wip` → `doing` · `#review` `#cho` → `review` · `#done` `#xong` → `done` | Token cuối cùng thắng. `#done` đi qua luồng hoàn thành chuẩn (ghi log Heatmap + streak) |
| Lịch nhắc | `@today` / `@homnay` → 17:00 hôm nay (sau 17:00 → +1 giờ, làm tròn 15 phút) · `@tomorrow` / `@ngaymai` → 09:00 hôm sau | `reminderAt` |
| Lặp lại | `@daily` / `@hangngay`, `@weekdays` / `@ngaythuong`, `@weekly` / `@hangtuan` | `recurrence` |

**Cố ý không hỗ trợ**: `@mai` (trùng tên người "Mai"), `#tag` (Task chưa có trường `tags`), `@monthly` (`RecurrenceType` chưa có chu kỳ tháng).

**Chặn tiêu đề rỗng**: nhập toàn token (VD `!pin ~15m`) → không tạo việc, hiện hướng dẫn. Áp dụng ở ô nhập dự án, dán nhiều dòng (bỏ qua dòng rỗng tên), Kanban quick-add, Command Palette và form mobile. Thanh chip `SmartCaptureHelperBar` hiển thị cảnh báo ngay khi gõ.

## 3. Bản quyền PRO — Ed25519 ngoại tuyến (`src/utils/licenseCrypto.ts`, `src/hooks/useProLicense.ts`)

### 3.1. Định dạng token
```text
STRIDE1.<base64url(JSON payload)>.<base64url(chữ ký Ed25519 64 byte)>
chữ ký = Ed25519(privateKey, UTF-8 của "STRIDE1.<payload>")
payload = { v: 1, product: "stride-tasks", licenseType, licenseKeyOrAddonId,
            activatedAt, pricePaidUsd, regionLabel, plan?, seats? }
```
- Xác thực bằng Web Crypto `Ed25519`; trình duyệt chưa hỗ trợ → tải động `@noble/ed25519` (chunk riêng ~8 kB).
- Mọi trường payload đều nằm trong chữ ký (không còn trường "không được ký" như bản nháp FNV-1a).

### 3.2. Vòng đời bản quyền trên thiết bị
- Lưu tại `STRIDE_PRO_LICENSE_V2` = token + các trường hiển thị.
- **Verify lại mỗi lần khởi động**, khi tab khác/DevTools sửa storage (`storage` event), khi khôi phục backup (`stride:license-changed`) và khi quay lại tab. Token sai **hoặc** bất kỳ trường hiển thị nào lệch payload đã ký → xóa bản ghi, trở về bản Miễn phí và thông báo.
- Kích hoạt theo 3 cách: **link 1-click** `https://tasks.nexuspulsetech.xyz/#activate=<token>` (app tự xử lý rồi xóa hash khỏi thanh địa chỉ), dán token/link vào ô kích hoạt, hoặc nhập tệp `.stride-license.json` (chỉ trường `token` được dùng để xác thực; tệp hỏng cú pháp → báo lỗi rõ ràng).
- Bản PRO có thể tải tệp chứng chỉ để kích hoạt thiết bị khác.
- **Honor-system**: như Sublime Text / Obsidian Catalyst — không có server kiểm soát số máy; gói nhóm (`plan: "team"`, `seats`) chỉ mang tính cam kết.

### 3.3. Phát hành bản quyền (`scripts/keygen.mjs`, chạy local — không nằm trong bundle)
```bash
npm run keygen -- init                 # tạo cặp khóa: private key → .env.local, public key → licenseCrypto.ts
npm run keygen -- check                # kiểm tra private key khớp public key đang nhúng
npm run keygen -- issue --id MANUAL-0001 --region vn-ppp [--out khach.stride-license.json]
npm run keygen -- issue --id TEAM-0001 --region team --seats 5
npm run keygen -- verify "<token hoặc link>"
```
- `init` **không in private key ra màn hình**. Mất private key = không phát hành thêm được; xoay khóa (`init --force`) làm mọi bản quyền cũ mất hiệu lực sau khi build lại.

## 4. Thương mại hóa (`src/config/commerceConfig.ts`, `StoreCommercialModal.tsx`)

### 4.1. Cờ & cấu hình (đọc lúc build — xem `.env.example`)
| Biến | Ý nghĩa |
| :--- | :--- |
| `VITE_ENABLE_PAYWALL` | `true` mới bật paywall. Mặc định tắt |
| `VITE_VIETQR_IMAGE_URL` | Ảnh VietQR; hỗ trợ placeholder `{amount}`, `{orderCode}` để tạo QR động |
| `VITE_LEMONSQUEEZY_CHECKOUT_URL` / `..._EMERGING` | Link checkout quốc tế ($25.95) / thị trường mới nổi ($14.95) |
| `VITE_LICENSE_CLAIM_URL` | URL Cloudflare Worker cấp bản quyền tự động (tùy chọn) |
| `VITE_SUPPORT_EMAIL` | Email hỗ trợ |

GitHub Actions (`deploy.yml`) đọc các biến này từ **Repository Variables**. Kênh nào chưa có URL → không hiện nút mua của kênh đó.

### 4.2. Vùng giá
- Mặc định `global-us` ($25.95). Chỉ chọn `vn-ppp` (199.000₫ ≈ $7.95) khi múi giờ `Asia/Ho_Chi_Minh` / `Asia/Saigon` hoặc ngôn ngữ trình duyệt là tiếng Việt. Người dùng có thể đổi vùng; hàng rào tự nhiên là phương thức thanh toán (VietQR cần tài khoản ngân hàng Việt Nam).
- Không hiển thị "giá gốc" gạch ngang.

### 4.3. Luồng thanh toán tự động 24/7 (`cloudflare-worker/src/index.js`)
1. App tạo mã đơn duy nhất `STRxxxxxx` (lưu `STRIDE_PENDING_ORDER_V1`, hết hạn sau 72 giờ).
2. **VietQR**: QR chứa số tiền + mã đơn → khách chuyển khoản → SePay gọi `POST /webhook/sepay` (xác thực `Authorization: Apikey …`, idempotent theo mã giao dịch, kiểm tra số tiền ≥ giá) → Worker ký token, lưu KV.
   **LemonSqueezy**: checkout kèm `checkout[custom][stride_ref]=<mã đơn>` → webhook `order_created` (xác thực HMAC-SHA256 `X-Signature`) → Worker ký token; nếu có `RESEND_API_KEY` sẽ gửi email chứa link kích hoạt.
3. App hỏi `GET /claim?order=<mã đơn>` mỗi 6 giây khi tab đang hiển thị → nhận token → tự kích hoạt (thường dưới 1 phút sau khi tiền về).
4. Không cấu hình Worker → hiển thị hướng dẫn gửi biên lai tới email hỗ trợ để nhận link kích hoạt thủ công.

### 4.4. Soft-gate dùng thử (chỉ khi paywall bật)
| Tính năng | Lượt thử | Khi nào trừ lượt |
| :--- | :---: | :--- |
| Kéo thả Kanban (đổi cột thật sự) | 3 | 1 lượt = **1 ngày** sử dụng kéo thả; xem bảng & phím `B` luôn miễn phí |
| Pomodoro | 3 | Khi một chu kỳ tập trung được ghi nhận (≥ 1 phút); bắt đầu phiên khi còn lượt |
| Báo cáo Markdown | 3 | Khi bấm **Sao chép** / **Tải .md** (mở xem trước miễn phí) |
| Dự án | tối đa 3 | **Không tính dự án mẫu**; người dùng đã có ≥ 3 dự án thật vào lần đầu paywall có hiệu lực trên thiết bị được **giữ quyền không giới hạn (grandfathering)** |

### 4.5. Công cụ nhà phát triển
"Giả lập PRO", "Hủy kích hoạt", "Đặt lại lượt dùng thử" chỉ tồn tại khi `import.meta.env.DEV` — Vite loại bỏ hoàn toàn khỏi bản build production (đã quét bundle xác nhận).

## 5. Lưu trữ & giới hạn `localStorage`
- Snapshot Vault giảm **20 → 5** bản sao toàn bộ workspace (tự cắt còn 2 khi hết quota).
- `completedLogs` cũ hơn **90 ngày** gộp thành `archivedDailyCounts` (`SOLO_COMPLETED_LOGS_ARCHIVE_V1`) — Heatmap vẫn đủ 365 ngày; bản ghi gốc chuyển sang IndexedDB.
- Gọi `navigator.storage.persist()` khi khởi động.
- Ghi thất bại (`QuotaExceededError` hoặc trình duyệt chặn storage) → toast cảnh báo rõ ràng (`stride:storage-error`).
- Sao lưu JSON toàn diện bao gồm `completedLogsArchive` và bản ghi bản quyền (token được verify lại khi khôi phục — không thể chèn PRO qua file backup tự chế).
- Bảng khóa đầy đủ: [`docs/architecture/state-persistence.md`](../architecture/state-persistence.md).

## 10. Checklist trước khi bật paywall
1. `npm run keygen -- check` → khớp; sao lưu `.env.local` an toàn.
2. Triển khai Worker, nạp secret, cấu hình webhook SePay & LemonSqueezy; chạy thử giao dịch thật giá trị nhỏ.
3. Khai báo Repository Variables trên GitHub, đặt `VITE_ENABLE_PAYWALL=true`, deploy.
4. Cập nhật `privacy.html` nếu thay đổi nhà cung cấp thanh toán; kiểm tra hộp thư hỗ trợ hoạt động.
