Dùng Trên Điện Thoại

Cài đặt web app toàn màn hình · Chạy offline 100%

🍎 1. Trên iPhone / iPad (Safari)

1. Mở file HTML hoặc link bằng trình duyệt Safari.

2. Chạm nút Chia sẻ (Share) ở thanh dưới (hình ô vuông có mũi tên trỏ lên).

3. Chọn "Thêm vào Màn hình chính" (Add to Home Screen).

✓ App sẽ mở toàn màn hình, không thanh URL, chạy 100% offline!

🤖 2. Trên Android (Chrome / Brave / Samsung)

1. Mở link bằng Chrome.

2. Chạm menu 3 chấm (⋮) góc phải trên.

3. Chọn "Cài đặt ứng dụng" (Install App) hoặc "Thêm vào MH chính".

✓ Hoạt động y hệt ứng dụng tải từ CH Play!

📁 3. Gửi file qua điện thoại dùng ngay

AirDrop file này sang iPhone, hoặc gửi qua Telegram/Zalo dạng file đính kèm. Mở bằng trình duyệt là dùng vĩnh viễn, dữ liệu lưu riêng trên máy.

📖

Hướng Dẫn Sử Dụng

Tối giản · Chạy offline 100% · Dữ liệu máy nào lưu máy đó

01. Chạy trên bất kỳ máy nào (100% Offline)

Chỉ cần lưu file vào USB, máy tính bàn, laptop (Windows, Mac, Linux) hay điện thoại. Nhấp đúp chuột là mở bằng trình duyệt dùng ngay lập tức, không cần cài đặt phần mềm nào.

02. Cơ chế "Máy nào lưu máy đó"

Sử dụng localStorage của trình duyệt. Dữ liệu được lưu thẳng vào máy tính bạn, không gửi lên bất kỳ máy chủ nào. Đóng tab hay khởi động lại đều còn nguyên.

03. Ghim việc ưu tiên & Chế độ tập trung (F)

Bấm 📌 để ghim lên "Tiêu điểm" đầu trang. Bấm biểu tượng 🎯 trên thanh tiêu đề để bật chế độ tập trung chống ngợp.

04. Chuyển dữ liệu giữa các máy khi cần

Bấm nút 💾 trên thanh tiêu đề để xuất file .json. Mang file đó sang máy khác bấm "Khôi phục" là toàn bộ dữ liệu chuyển qua ngay lập tức.
